# Aani Social

نسخة Replit مستقلة للتطبيق الاجتماعي المرفق. لم تُربط بمشروع Supabase الأصلي،
ولم تُستورد منها سجلات أو تُنفّذ عليها تغييرات قاعدة بيانات.

## الميزات الموجودة

- تسجيل الدخول وإنشاء الحساب والملفات الشخصية والمتابعة والبحث.
- المنشورات النصية والصور ومقاطع الفيديو، مع الإعجابات والتعليقات والحفظ
  وإعادة النشر.
- القصص والريلز والرسائل المباشرة الفورية والإشعارات.
- مساعد محادثة عربي يرسل الطلب إلى دالة Supabase Edge محمية.
- واجهة عربية من اليمين إلى اليسار، مع تخطيط متجاوب وتحسينات لوحة المفاتيح.

## التشغيل والفحوصات

```sh
pnpm install
pnpm --filter @workspace/aani-social run typecheck
pnpm --filter @workspace/aani-social run typecheck:edge
pnpm --filter @workspace/aani-social run test:edge
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/aani-social run build
```

يستخدم التطبيق Supabase مباشرة للمصادقة وقاعدة البيانات والتخزين وRealtime؛ لا
يستخدم PostgreSQL المرفق بقالب Replit أو خادم API التجريبي لهذا الغرض.

## إعداد الاتصال

في Replit Secrets أضف:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY` أو `VITE_SUPABASE_ANON_KEY`
- `VITE_SUPABASE_STORAGE_BUCKET` اختياري؛ الافتراضي `aani-media`

إذا كان مشروع Supabase القائم يستخدم حاوية تخزين اسمها `media`، عيّن
`VITE_SUPABASE_STORAGE_BUCKET=media` بدل نقل الملفات أو إعادة تسمية الحاوية.
لا تضع مفتاح `service_role` أو مفتاح Gemini في واجهة المتصفح.

في أسرار Supabase Edge Functions أضف `GEMINI_API_KEY` و`ALLOWED_ORIGINS`؛
`GEMINI_MODEL` اختياري. لا يُخزّن مفتاح Gemini في Replit. تفاصيل الإعداد والنشر
في [`docs/SETUP_AR.md`](./docs/SETUP_AR.md).

## قاعدة البيانات والوسائط

يحوي `supabase/schema.sql` المخطط الكامل (الجداول، السياسات، الفهارس، ومُشغّلات
عدادات التفاعل ودالة `post_interaction_summaries`) وأصبح آمنًا لإعادة التشغيل،
لذا يكفي تنفيذه مرة واحدة على مشروع Supabase جديد.

لتفعيل التفاعلات الحقيقية على مشروع قائم، نفّذ ترحيل التفاعلات:

```
supabase/migrations/20261026000000_interaction_persistence.sql
```

وهو يضيف أعمدة العدادات `likes_count` و`comments_count` و`reposts_count`
و`shares_count` إلى `posts`، وجداول `bookmarks` و`reposts` و`post_shares`
و`notifications` مع سياسات RLS، ومُشغّلات تُحدّث العدادات تلقائيًا عند كل
إعجاب/تعليق/إعادة نشر/مشاركة، ودالة `post_interaction_summaries()` التي تُرجع
العدادات وحالة المستخدم في نداء واحد. الترحيل يحوي تعبئة (backfill) للعدادات من
الصفوف الموجودة، لكنه لا يحذف أي سجل. خذ نسخة احتياطية قبل تطبيقه على مشروع حي.

لتفعيل الردود ومرفقات التعليقات والإعجاب وعدم الإعجاب على مشروع قائم، نفّذ بعده
الترحيل `supabase/migrations/20261029000100_comment_threads_reactions.sql`.
هذا الترحيل إضافي ولا يحذف التعليقات الموجودة؛ يستخدم حاوية الوسائط الحالية
ويضيف سياسات RLS للمالك والقراءة للمستخدمين المسجلين.

ملف `supabase/migrations/20261025000000_social_features.sql` يبقى للقصص
والإشعارات. سياسة القصص الخاصة بالأصدقاء المقرّبين في ذلك الترحيل تعني المتابعة
المتبادلة. إذا كان مشروعك يستخدم قائمة أصدقاء مقربين مستقلة، راجع هذه السياسة
قبل تطبيق الترحيل.

لتفعيل إجراءات المحادثات (الحذف لدي، والحذف لدى الجميع)، نفّذ الترحيل
`supabase/migrations/20261202120000_message_conversation_controls.sql` على مشروع
Supabase. الحذف لدى الجميع يمسح كل رسائل المحادثة للطرفين، بينما يخفي الحذف لدي
الرسائل الحالية عن صاحب الحساب فقط، وتظهر الرسائل الجديدة لاحقًا بشكل طبيعي.
إعدادات التثبيت والأرشفة والكتم محفوظة محليًا على الجهاز الحالي. لتفعيل علامات
الإرسال والتوصيل والقراءة، نفّذ أيضاً ترحيل
`supabase/migrations/20261204000000_message_delivery_receipts.sql`؛ الترحيل
يضيف طوابع التوصيل والقراءة ودوالاً آمنة لتحديثها من حساب المستلم.

## ملاحظات أمنية

- ملف النشر `fix.js` واللقطة النصية المحتوية على اعتماد مضمّن لم يُنسخا إلى
  التطبيق ولم يُشغّلا. أكد المستخدم إلغاء الاعتماد المكشوف.
- لا تملك دالة Gemini أدوات لتعديل ملفات Replit أو تنفيذ أوامر أو إدارة قاعدة
  البيانات. دالة `gemini-chat` تتحقق من جلسة المستخدم، وتقيّد المصادر والمدخلات
  والمهلة، وتعيد عقد `{ text, model, finishReason, requestId }`.
- `ai-assistant` مسار توافق قديم ويتطلب تسجيل الدخول أيضًا. تحقق من أي عميل
  قديم قبل نشر هذا التغيير إليه.
- لم يُجرَ اختبار تسجيل دخول أو قراءة/كتابة أو محادثة حقيقية؛ تتطلب هذه
  الاختبارات إعداد Supabase وGemini المملوكين لك.

## نتائج التحقق السابقة

- فحص TypeScript للواجهة: ناجح.
- فحص TypeScript لدوال Supabase: ناجح.
- اختبارات الدالة بمحاكاة HTTP: 6 ناجحة.
- بناء Vite: ناجح؛ يعرض تحذيرًا غير مانع عن مصدر خرائط `tooltip` وحجم حزمة
  JavaScript يتجاوز 500 كيلوبايت.


## الإيموجي والملصقات

- تظهر الإيموجيات بخط الجهاز المحلي؛ يستخدم iOS وmacOS خط Apple Color Emoji المثبت مسبقاً، من دون تنزيل صور أو ملفات خطوط خارجية.
- `src/data/emoji-catalog.json` بيانات الفئات والأسماء ومتغيرات لون البشرة مضمنة محلياً في التطبيق، لذا لا توجد حالة تحميل لقائمة الإيموجي.
- متجر الملصقات الحالي كتالوج مدمج، وتثبيت الحزم والمكتبة المخصصة محفوظان محلياً لكل مستخدم على الجهاز. ملفات الملصقات الشفافة ترفع إلى حاوية Supabase الإعلامية الحالية، وتُرسل الرسائل برابط الصورة.
- القص التلقائي يزيل ألوان الخلفية المتصلة بحواف الصورة، والقص الحر يعتمد على تحديد المستخدم؛ لا يستخدم أي منهما تقسيمًا دلاليًا بالذكاء الاصطناعي. يدعم الاستوديو حفظ PNG أو WebP شفافاً.
- نتائج الفحص المسجلة أعلاه تخص الحالة السابقة لهذه الإضافة؛ لم يُشغّل فحص محلي لهذه التغييرات.
